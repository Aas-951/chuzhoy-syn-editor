# Редактор «Чужой сын»

Это публичный репозиторий приложения `Aas-951/chuzhoy-syn-editor`. Здесь не должно быть текстов романа, заметок автора, ключей или файлов резервных копий с личными данными.

## Работа с романом из GPT и Claude

Закрытое хранилище данных: `Aas-951/chuzhoy-syn-vaal`, ветка `main`.
Локальная рабочая копия: `C:/Users/and/.t3max/projects/chuzhoy-syn-vaal`.

Если задача о тексте, заметках или предложении главы, сначала перейти в эту закрытую рабочую копию, прочитать её `AGENTS.md` и `редактор/README.md`, проверить `git status` и получить свежие изменения без перезаписи чужой работы. Не хранить литературные результаты в этом публичном репозитории.

Две параллельные редакции: Codex (ID `gpt01`…`gpt17`) и Адриан Ваал (ID `prolog`, `ch01`, `ch02`, `interlude01`, `ch03`). Не смешивать. ID в задании с телефона однозначен. Если редакция из запроса не ясна, уточнить её до литературных правок.

Ответы писать в `replies` от имени `GPT` или `Claude`. Литературные правки оформлять предложением с точным базовым blob SHA; автор принимает его на телефоне. Саму главу менять только по прямому заданию. После изменения приватных данных проверить JSON, commit и push только своих файлов; force push запрещён.

## Работа с приложением

Приложение — статические `index.html`, `app.js`, `style.css`, `sw.js`. После изменения приложения увеличить CACHE в `sw.js`. Проверка: `node --check app.js`, `node --check sw.js`, `node --test tests/*.test.cjs`. Для публикации используется обычный GitHub Pages из этого репозитория. Никогда не ослаблять приватность хранилища романа.
