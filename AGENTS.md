После изменения приватных данных проверить JSON, commit и push только своих файлов; force push запрещён.

## Работа с приложением

Перед продолжением работы прочитать [HANDOFF.md](HANDOFF.md): там состояние переноса старого редактора, общий порядок GPT/Claude в T3 Max, проверки и ограничения. Дополнять этот журнал после существенного изменения приложения; не включать в него тексты романа или заметки автора.

Приложение — статические `index.html`, `app.js`, `style.css`, `sw.js`. Главный экран открывается блоком «Ждёт вас» (`inbox()` в `app.js`): это предложения со статусом `pending` и открытые заметки, на которые последним ответил агент, по обеим редакциям. Предложения сравниваются по абзацам, правки нумеруются. Требования к `summary` и ответам описаны в `редактор/README.md` закрытого хранилища. После изменения приложения увеличить CACHE в `sw.js` и тот же номер в `APP_VERSION` в `app.js` (его видно в «Настройках»). Проверка: `node --check app.js`, `node --check sw.js`, `node --test tests/*.test.cjs`. Для публикации используется обычный GitHub Pages из этого репозитория. Никогда не ослаблять приватность хранилища романа.
