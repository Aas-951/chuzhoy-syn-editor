# Чужой сын — редактор

Редактор романа для телефона: https://aas-951.github.io/chuzhoy-syn-editor/

Здесь только сам редактор, текста романа в этом репозитории нет. Главы и заметки лежат в закрытом репозитории `Aas-951/chuzhoy-syn-vaal`. Редактор читает и пишет его через GitHub API с ключом, который вводится на телефоне один раз.

- Работает без Интернета: главы хранятся на телефоне, правки и заметки копятся в очереди и отправляются, когда появляется сеть.
- Без сборки: `index.html`, `app.js`, `style.css`, `sw.js`. Чтобы обновление дошло до телефонов, увеличьте номер `CACHE` в `sw.js`.
- Формат заметок и предложений для агентов описан в `редактор/README.md` закрытого репозитория.

В редакторе две параллельные редакции: **Codex · 17 глав** и **Адриан Ваал**. Их тексты и заметки разделены постоянными ID. Переключение редакции доступно в списке глав. Во вкладке заметок кнопки «Задание для GPT» / «Задание для Claude» копируют поручение для вставки в чат T3.

Первый запуск и полная загрузка глав требуют Интернета. После успешной синхронизации можно читать, править, оставлять заметки и ответы без сети. Они сохраняются в памяти этого браузера и отправляются при восстановлении связи, возвращении в приложение или нажатии «Синхронизировать». Для общения с GPT/Claude нужен Интернет. Не очищайте данные сайта, если есть неотправленные правки. Редактор проверяет SHA перед заменой главы; конфликтующая версия сохраняется отдельным файлом.

На телефоне откройте редактор, введите личный fine-grained GitHub token только для `chuzhoy-syn-vaal` с разрешением Contents: Read and write. Ключ не отправляйте агентам и не сохраняйте в репозиторий. Дождитесь загрузки глав, затем добавьте редактор на главный экран. На каждом новом устройстве вход и первоначальная загрузка выполняются отдельно.

Общие инструкции для GPT и Claude находятся в `AGENTS.md`; здесь указан путь к локальной копии закрытого хранилища.

Проверка синхронизации: `node --test tests/*.test.cjs`. Тесты используют вымышленные данные в памяти и не записывают ничего в настоящий GitHub.
